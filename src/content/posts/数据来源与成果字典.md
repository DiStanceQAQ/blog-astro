## 数据分三层

**原始数据**保存来源和原始含义；**处理数据**保存空间、时间及单位统一后的字段；**模型产物**保存一次确定输入条件下的模拟结果。不要让同名文件在无记录情况下从“试跑数据”变成“正式数据”。

| 数据 | 用途 | 当前关键限制 |
|---|---|---|
| WRF 输出/逐日诊断 | 区域气象驱动作物模型 | 必须核对完整生长季、单位、累计量和时间边界 |
| ERA5/ERA5-Land | 原方案气象资料；现有脚本试跑输入 | 再分析产品用途应分清；当前试跑缺雨量和短波，不能代表产品本身缺这些变量 |
| 2019、2023 农田地块 | 地块几何和跨年对照 | 2020 实验不能默认 2023 边界与作物归属不变 |
| 作物分布 | 玉米纯度和样本筛选 | 保留年份、类别编码、分辨率和混合像元比例 |
| SoilGrids | 土壤属性代理 | 纹理类别不等于实测分层水力参数 |
| DEM | 地形与分层辅助 | 地形数据存在不等于已经实现气象地形订正 |
| MODIS LAI/ET/GPP | 冠层、耗水和生产力辅助评价 | 有质量标志、合成周期及空间混合，不是无误差真值 |
| 统计产量/物候/管理观测 | 本土化与独立验证 | 需要继续确认可用年份、地域及计量口径 |
| DB65 定额与网格区划 | 用水约束 | 核实标准版本、适用区、作物、灌溉方式和净毛口径 |

## 项目位置与状态

本地研究项目：`本地路径`。本地开题材料：`本地路径`。

历史 Windows 配置中的工作根目录为 `本地路径`。以下是历史记录和配置给出的产物位置，**本次未在 Windows 实机确认其当前内容**。

| 相对路径 | 内容与建议唯一键 |
|---|---|
| `processed/parcel_base.parquet` | 地块属性；`parcel_id` |
| `processed/weather_daily.parquet` | 天气；单运行版本内 `wrf_grid_id + date` |
| `processed/response_units.parquet` | 响应单元；`response_unit_id` |
| `processed/response_membership.parquet` | 地块归属及权重；一版划分内 `parcel_id` |
| `outputs/response_baseline.parquet` | 季节结果；单批次内 单元 + 年份 + 策略 |
| `outputs/response_baseline_daily.parquet` | 当前脚本定义的逐日状态产物；需另核实实际生成情况 |
| `metadata/qa_report.json` | 质量检查记录 |
| `metadata/variable_dictionary.json` | 变量字典 |
| `metadata/artifact_manifest.json` | 产物清单 |

未来合并多批实验时还应加入 `run_id`、`weather_scenario_id`、`parameter_set_id`，否则同一单元/年/策略可能对应多个不同结果。这里是建议的数据契约，不声称所有字段已实现。

## 核心变量口径

| 字段/概念 | 单位或范围 | 使用时注意 |
|---|---|---|
| `area_m2` | m² | 面积计算使用合适的投影/测地方法，不能把经纬度面积当平方米 |
| `crop_purity` | 0—1 | 地块中目标作物的覆盖比例，不是分类置信概率 |
| `area_weight` | 单元内归一化权重 | 应检查每个单元权重和为 1 |
| `tmin` / `tmax` | 目标为 ℃ | 输入脚本不会自动把 K 转 ℃ |
| `precipitation` | 目标为 mm/day | 日累计，不是瞬时率或从启动时刻累计的总量 |
| `et0` | mm/day | 参考蒸散，不是实际作物 ET；须记录计算方法 |
| `radiation` | 须明确为 W/m² 均值或 MJ/m²/day | 当前字段名本身不能证明单位 |
| `yield_t_ha` | t/ha，脚本优先读取干产量 | 与统计产量比较须匹配含水率等口径 |
| `seasonal_irrigation_mm` | mm/season | 核实是净入田水量还是引水总量 |
| `seasonal_et_mm` | mm/season | 当前脚本对 Es + Tr 求和，缺列兜底会影响可信度 |
| `max_canopy` | 一般为覆盖比例，需核对版本 | 不等于 LAI |
| `quality_flag` | 分类状态 | 通过数值检查不等于经过独立科学验证 |

换算：1 ha = 10,000 m²；1 mm × 1 ha = 10 m³；1 m³/亩 = 1.5 mm。

若地块产量为 $Y_p$（t/ha）、面积为 $A_p$（ha），总产为 $\sum_p A_pY_p$，区域平均单产为 $\sum_p A_pY_p/\sum_p A_p$。不能直接相加单产，也不能拿模拟单产与县级总产比较。

## 版本和来源建议

每套输入保留下载/获取日期、产品版本、年份、坐标系、单位、处理脚本版本及哈希。每次实验冻结一份清单。来源不明的默认参数应明确标为“假设”，不标为“实测”。
